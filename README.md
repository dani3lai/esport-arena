# Esport Arena – pierwsza wersja

## Uruchomienie
1. Zainstaluj Node.js 20+.
2. W folderze projektu uruchom:
   npm install
   npm run dev
3. Otwórz adres pokazany przez Vite.

## Funkcje demonstracyjne
- lokalne logowanie użytkownika
- dashboard e-sportowy
- responsywna drabinka Single Elimination
- statusy meczów
- chat działający w bieżącej sesji
- opcjonalny tryb administratora i edycja wyników
- zapis nazwy użytkownika w localStorage

## Następny etap produkcyjny
Backend: Node.js + Express/NestJS
Baza: PostgreSQL + Prisma
Autoryzacja: JWT + bcrypt
Chat: Socket.io
